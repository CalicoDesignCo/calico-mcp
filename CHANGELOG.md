# 0.1.0-beta.32

Preserve unchanged existing addon settings omitted during Elementor document serialization. Do not resurrect explicitly removed controls or bypass validation for new/changed values. Unexpected alterations to unrelated controls fail and restore the prior layout. Adds seven regression assertions;217 exact-package local checks and14 focused host checks passed.

# 0.1.0-beta.31

Add optional shared-template editing and bounded Yoast organization social-profile tools, with independent default-off permissions, revision protection and Undo. Keep durable OAuth client registrations across scope changes while revoking tokens/codes. The first host header trial exposed the addon preservation issue fixed in beta32; do not interpret that trial as a successful beta31 preservation test.

# 0.1.0-beta.30

Allow explicit ownership recovery when the configured WordPress account no longer exists. Preserve selected permissions/fields, revoke prior sessions and leave AI access disabled until reviewed.
